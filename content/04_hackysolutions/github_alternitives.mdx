Are you running a Hack Club? Is GitHub blocked at your school? Here are some workarounds.

Firstly, the best case scenario. GitHub is the industry standard tool for open sourcing (sharing), used by millions of developers worldwide, code and by using it allows you and your club members to get hands-on experience with tools that you will use if you decide on a career in tech. If possible try explaining to your teachers or IT department this and see if it can be unblocked, even if it is only during supervised times at meetings that is perfectly fine. 

We understand that this might not be possible, so here are some alternatives that Hack Club supports when submitting to programs. All of the options below give you a public repo link, so you can still submit to any Hack Club YSWS (You Ship, We Ship) program that asks for one.

- [git.hackclub.app](https://git.hackclub.app)
- Your own git server ([Gitea](https://about.gitea.com/), [Forgejo](https://forgejo.org/), etc). Note that this needs a publicly accessible server to host it on (for example a [Hack Club Nest](http://hackclub.app) project), so it takes more setup than the other options here.
- [Codeberg](https://codeberg.org/)
- [GitLab](https://about.gitlab.com/)

To submit to Web Development YSWS’s you need a Live Playable URL to show your site. Here are some examples of hosting platforms

- [Vercel](https://vercel.com/)
- [Netlify](https://www.netlify.com/)
- [Codeberg Pages](https://docs.codeberg.org/codeberg-pages/)
- [Hack Club Nest](http://hackclub.app)

For more workarounds if git hosts aren't your only blocked resource, see [Hacky Solutions](/view/04_hackysolutions/hacky_solutions).
